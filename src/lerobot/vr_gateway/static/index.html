CONTROLLER GUIDE

握住跟随，松开保持

左右手独立控制。每次握持都以当前手柄和机械臂位置为起点。

Grip

机械臂跟随

按住侧握键，平移或转动手柄；松开后保持该侧机械臂。

Trigger

按住打开，松开闭合

夹爪默认闭合，食指扳机按得越深打开越大。无需同时按住 Grip。

自动对齐 · Y

朝向对齐

开始握持时自动对齐头部朝向；中途加入的手沿用同一方向。双手松开后重新对齐，Y 可手动重置。

摇杆 · A / B

底盘与升降

左摇杆前后与横移，右摇杆转向；A 下降，B 上升。机械臂跟随时互锁。
